## 3. TurnEventType 18-Member Delivery Accounting (`omicsclaw/entry/events.py:41-106`)

  `EXCHANGE_START` (stream open / `SessionStreamSnapshot`), `APPROVAL_SETTLED` (resolved via `POST /chat/permission` -> queue advance), `QUESTION_SETTLED` (resolved via `POST /chat/question` -> `AskUserHistoryCard`), `TURN_END` (projected at stream termination via `desktop_terminal_frames` as `result` usage ledger), and `EXCHANGE_END` (projected at stream termination via `desktop_terminal_frames` as `result` + `error` + `done`).
