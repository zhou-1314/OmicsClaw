## 实验设计约束

研究主线是让诊断证据改变后续方法，首期检验可回答性与科学恢复。结论稳定性后续扩展。相同模型、工具、数据与预算下，比较基线、等预算提示增强、单项机制与组合机制；终点指标之外记录诊断、行动和验证三个阶段。评分器与隐藏答案放在 Agent 不可访问的位置。

GeneBench-Pro 已包含多种组学任务；本方案不声称填补“没有组学评测”的空白。论文提出过阶段性评分的后续方向，本方案也不将该想法单独作为创新。机制的新颖性和真实数据迁移能力仍需独立文献比较与实验证明。
