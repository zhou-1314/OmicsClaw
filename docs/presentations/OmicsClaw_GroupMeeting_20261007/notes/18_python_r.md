Python 和 R 通过明确的文件接口共享证据。Python 每个步骤使用新 kernel，不能依赖前一步留在内存里的变量；R 步骤在一个 Rscript 进程中按顺序执行各个 cell。跨步骤用 MTX、CSV 等文件传递内容，输入输出及其哈希进入记录。

这个选择牺牲了一部分交互式内存复用便利，换来步骤边界更明确，也更容易从头重放。运行记录包含解释器、R 版本、已加载包版本、文件哈希和日志。混合模块最后仍由 Python validate 步骤核对输出，形成同一条证据链。
