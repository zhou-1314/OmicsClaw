tools 提供注册、暴露定义和执行三个环节。文件、bash、web 和 MCP 工具都进入同一套 registry，工具定义保持稳定的注册顺序，避免同一组工具在不同请求中无故变化。

并发并不是看到多个调用就全部同时启动。工具先声明执行策略，engine 据此编排：明确可安全并发的读取可以一起运行，独占写入会形成边界，再进入下一批调用；结果仍按原调用顺序回填。未声明并发安全的调用默认独占，减少同批写入相互覆盖的问题。

另一个容易忽略的细节是审批等待暂停工具计时。人在判断是否允许时，工具实际上还没有执行，不能把这段时间混进执行超时。registry 提供策略，engine 管理调度，职责分工见 omicsclaw/tools/registry.py 和 omicsclaw/engine/。
