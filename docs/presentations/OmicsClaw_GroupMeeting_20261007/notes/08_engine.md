engine 维护 ReAct 主循环：已有消息交给模型，模型提出 ToolCall，执行后产生 ToolResult，再把观察放回消息历史。只要模型还需要工具，就继续这个循环；模型不再请求工具时返回最终回答。

run 和 run_stream 共用一个内核，前者返回完整结果，后者逐步发出事件。这样终止条件、预算和工具处理不会因为输出方式不同而形成两套实现。错误直接抛出，取消继续向上传播，不把失败包装成一个看起来正常的完成结果。

engine 只负责循环本身。提示如何构造、会话如何保存、具体工具怎样实现，都由外部组件承担。这使核心循环能用脚本化 provider 和替代工具测试，而不必启动完整科学环境。实现集中在 omicsclaw/engine/loop.py。
