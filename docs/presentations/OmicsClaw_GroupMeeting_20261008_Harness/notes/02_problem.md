假设用户要求分析一份单细胞数据，一次模型回答无法提前知道文件质量、实际依赖、批次结构和分析中途的报错。教程第一讲由这个问题引入运行时：模型负责下一步决策，框架负责把环境观察、工具执行和状态持续接回决策。

在 OmicsClaw 中，复杂性一部分来自方法与环境：Python、R 和命令行混用，数据库和输入契约也不同；另一部分来自过程与证据：参数变动后下游是否过期，离开原会话后能否重跑，报告是否对应当前输出。因此需要同时提供可发现的方法、可运行的环境、显式步骤和验证材料。

后面每层都按照同样的追问展开：缺少它会出什么问题，它接收和改变什么，怎样证明行为符合约定。动态 Agent 决策与科学流程的显式依赖可以并存，不需要把所有固定流程或 DAG 都判断为不合理。
