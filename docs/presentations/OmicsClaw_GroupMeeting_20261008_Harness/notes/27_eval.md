教程第二十讲把评价标准从“回答听起来正确”转向“环境实际上发生了什么”。OmicsClaw 的 Case 经生产 build_app 组装，再通过 SessionRegistry 提交请求，记录轨迹、审批和临时工作区前后差异，最后运行断言。

ScriptedProvider 预设模型会发出的调用和回复，用来稳定复现机制问题。例如 ToolCalled、ToolArgs 检查动作与参数，NoWriteOutside 检查越界副作用，审批和调用次数也有对应检查。这些能发现组装路径没有接通的问题，却不能证明真实模型一定会选择正确技能。

真实模型路由评估另用二十六个种子，需手动启用，可以重复 trial；服务故障与路由质量分开报告，成功率本身不是该测试的硬失败阈值。完成情况、越界行为、耗时与 token 都有用，但科学结论仍需真实数据与统计验证。本次没有新跑性能对照，因此没有给出提升曲线。
