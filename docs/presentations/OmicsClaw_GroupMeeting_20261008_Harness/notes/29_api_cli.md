函数库与 CLI 面向不同使用场景。_api.py 接受数据和参数，返回数据对象或 Figure，分析 step 通过 load_skill 组合这些方法并明确写出结果。薄 CLI 继续负责参数解析、读取文件、报告和展示，不需要研究人员放弃已有命令行用法。

当前八十三个技能暴露函数库，五个保留 CLI。计算与外部获取也区分开：网络动作明确命名为 fetch_*，不能让普通计算悄悄联网。DataFrame 的运行诊断放在 attrs 中并通过 run_info 读取，CSV 不保留 attrs，因此写表格时还需要保存必要的诊断说明。

XCMS 是明确的合成 demo-only CLI，遇到真实 raw-MS 输入会拒绝，不能将随机示例当作真实峰处理。边界和兼容性证据见计划 0074、0075、0076，以及各技能的公开 API 文档。
