# 计划 0056：ensemble 实施取舍（历史）

ensemble 实现已删除，代码存档在 tag `archive/ensemble-before-removal`。本记录保留实施取舍和 owner 裁定，旧测试、冒烟与面板偏差结果已清理。原设计见 [计划 0056](0056-ensemble-foundation.md)。

## 实施取舍

- 调度使用 `asyncio`，执行器通过 `BashEnvironment` 运行方法，框架进程不导入科学计算包。
- GPU 设备信息区分进程观测、技能自报和无租约推断。PID 命名空间不一致时，不将技能自报值当作进程观测值。
- 控制平面凭据在框架启动子进程时清理，技能代码不承担这项职责。
- 输入哈希和输入描述分别设超时，计入整次调用预算；超时要留下结构化结果。
- 每个试验保留输入摘要、标签、指标、监督记录和运行日志，临时目录在收尾时清理。

## owner 裁定

- PyYAML 由 conda 环境提供，不加入核心 pip 依赖。
- 后续 benchmark 在预处理完成后剥离额外 `obs` 列，只保留 `batch`。
- 当时的部署允许执行环境自检失败后告警，并不挂载 `run_skill`。这属于已退役 ensemble 的行为。

这些决定仅解释旧实现，当前架构的能力和验证入口以实际代码为准。
